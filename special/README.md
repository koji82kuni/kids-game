# スペシャル画像フォルダ

まなびのゲームで **全問正解したとき** に、お祝いとして出てくる画像を入れる場所です。

## 画像を増やすとき

1. この `special` フォルダに画像ファイルを入れる
2. ファイル名は**半角の英数字**にする（例：`umi_no_ko.jpg`）
   - 日本語のファイル名だと表示できないことがあります
3. Claudeに「スペシャル画像を追加した」と伝える（GitHubへのアップロードが必要なため）

ファイルを入れるだけでゲーム側の設定変更は不要です。
ゲームは表示のたびにこのフォルダの中身を読みに行き、見つかった画像から1枚を選んで出します。

## 画像の推奨

| 項目 | 目安 |
|---|---|
| 形式 | JPG（PNG・WEBP・GIFも可） |
| 横幅 | 1200px 程度まで |
| 容量 | 1枚 300KB 以内が快適 |

大きすぎる画像は表示に時間がかかるため、Claudeに渡してもらえれば圧縮します。
